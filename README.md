# Express.js CRUD API

This project is a RESTful CRUD API built using Node.js, Express.js, and MongoDB with Mongoose. It provides a simple and efficient backend solution for managing user information through standard HTTP methods.

The application supports all essential CRUD (Create, Read, Update, Delete) operations, allowing users to create new records, retrieve all users, fetch individual user details, update existing information, and delete user records.

The API uses Express.js for server-side routing and request handling, while MongoDB serves as the database for storing user information. Mongoose is used for schema definition, data validation, and database operations.

### Key Features
- Create new user records.
- Retrieve all users.
- Get individual user details by ID.
- Update existing user information.
- Delete user records.
- Mongoose schema validation.
- RESTful API architecture.
- API testing using Thunder Client.

### Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript (ES Modules)
- Thunder Client

### Purpose
The primary objective of this project is to understand and implement RESTful API development, backend architecture, database integration, routing, middleware, and CRUD operations using the Node.js and Express.js ecosystem.
